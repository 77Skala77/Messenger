# AI Workflow — Secure Messenger MVP

This folder contains project-specific Codex workflow rules for Secure Messenger MVP.

These files are not a full ECC installation.

They are a small ECC-inspired guardrail system adapted to this repository.

## Files

- ../../AGENTS.md — main Codex rules for this repository.
- SECURITY_CHECKLIST.md — security checklist for sensitive changes.
- TESTING_CHECKLIST.md — testing checklist for implementation work.
- RELEASE_CHECKLIST.md — release/build handoff checklist.
- HANDOFF.md — context-preservation file between Codex sessions.
- PROMPTS_FOR_CODEX.md — ready prompts for common Codex workflows.

## Scope

These rules apply only when Codex works in this repository.

Do not copy Messenger-specific rules into global Codex memory.

Other projects should have their own project-specific AGENTS.md and workflow files.
